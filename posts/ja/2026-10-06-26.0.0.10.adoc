== Java 27 のサポート

Java 27 は、Java の最新バージョンです。以前のバージョンの Java と比べて、確認が必要ないくつかの新機能と拡張機能が含まれています。このリリースは長期サポート (LTS) リリースではありません。

Java 27 には 9 つの新機能 (JEP) があります。そのうち 5 つはテスト機能で、4 つは完全に提供されています。

*テスト機能:*

* 531: link:https://openjdk.org/jeps/531[Lazy Constants (Third Preview)]
* 532: link:https://openjdk.org/jeps/532[Primitive Types in Patterns, instanceof, and switch (Fifth Preview)]
* 533: link:https://openjdk.org/jeps/533[Structured Concurrency (Seventh Preview)]
* 537: link:https://openjdk.org/jeps/537[Vector API (Twelfth Incubator)]
* 538: link:https://openjdk.org/jeps/538[PEM Encodings of Cryptographic Objects (Third Preview)]

*提供された機能:*

* 523: link:https://openjdk.org/jeps/523[Make G1 the Default Garbage Collector in All Environments]
* 527: link:https://openjdk.org/jeps/527[Post-Quantum Hybrid Key Exchange for TLS 1.3]
* 534: link:https://openjdk.org/jeps/534[Compact Object Headers by Default]
* 536: link:https://openjdk.org/jeps/536[JFR In-Process Data Redaction]

JEP 523 に関する重要な注意事項です。JEP 523 により、Java 27 ではデフォルトのガーベッジ・コレクターが変更されます。G1 ガーベッジ・コレクター (GC) が、以前は Serial GC または Parallel GC を使用していた環境 (たとえば、シングル CPU の環境や、コンテナーなどのメモリーが少ない環境) を含め、すべての環境でデフォルトになりました。リソースが制約された環境で Liberty を実行している場合、以前の Java リリースとは異なる GC の動作に気付くことがあります。以前のガーベッジ・コレクターに戻すには、`-XX:+UseSerialGC` または `-XX:+UseParallelGC` を使用してください。

今すぐ新しい変更を活用して、Java 27 で実行されるアプリケーションとマイクロサービスを評価するための時間を増やしてください。

link:https://developer.ibm.com/languages/java/semeru-runtimes/downloads/[IBM Semeru Runtimes 27] または link:https://jdk.java.net/27/[Java 27] をダウンロードし、link:https://openliberty.io/downloads/#runtime_releases[26.0.0.10] をダウンロードしてインストールします。次に、Liberty サーバーの link:https://openliberty.io/docs/latest/reference/config/server-configuration-overview.html#server-env[`server.env`] ファイルで `JAVA_HOME` を Java 27 のインストール・ディレクトリーに設定して、テストを開始してください。

Java 27 の詳細については、Java 27 の link:https://jdk.java.net/27/release-notes[リリースノート・ページ]、link:https://download.java.net/java/early_access/jdk27/docs/api/[Javadoc]、または link:https://jdk.java.net/27/[ダウンロード・ページ]を参照してください。
Open Liberty の詳細については、link:https://openliberty.io/docs[ドキュメント・ページ]を参照してください。

== 26.0.0.10 を使用したアプリケーションの開発と実行

link:{url-prefix}/guides/maven-intro.html[Maven] を使用している場合は、`pom.xml` ファイルに以下を含めてください:

[source,xml]
----
<plugin>
    <groupId>io.openliberty.tools</groupId>
    <artifactId>liberty-maven-plugin</artifactId>
    <version>3.12.3</version>
</plugin>
----

link:{url-prefix}/guides/gradle-intro.html[Gradle] の場合は、`build.gradle` ファイルに以下を含めてください:

[source,gradle]
----
buildscript {
    repositories {
        mavenCentral()
    }
    dependencies {
        classpath 'io.openliberty.tools:liberty-gradle-plugin:4.0.2'
    }
}
apply plugin: 'liberty'
----
