== MicroProfile 7.0 でマイクロサービス・アプリケーションを開発する

MicroProfile は、軽量で効率的な方法でマイクロサービスを開発、デプロイ、管理するための API とツールのセットを提供します。24.0.0.12 リリースでは、メジャーリリースである MicroProfile プログラミング・モデル・バージョン 7.0 のサポートが追加されました。これは MicroProfile Metrics を MicroProfile Telemetry に置き換えます。したがって、MicroProfile Metrics はアンブレラ・リリースから外れ、スタンドアロン仕様になります。このリリースでは、MicroProfile OpenAPI、Rest Client、Fault Tolerance、および Telemetry 機能の新しいバージョンも導入されます。詳細については、link:{url-prefix}/blog/2024/12/03/microprofile-7.html[MicroProfile 7.0 deep dive with Open Liberty] を参照してください。

== SameSite=None 互換性のないクライアントをチェックする

24.0.0.12 では、特定のクライアント・バージョンを壊す心配なく `SameSite=None` Cookie を使用できるようになりました。以前は、`SameSite=None` 属性を持つ Cookie は、link:https://www.chromium.org/updates/same-site/incompatible-clients/[互換性のないクライアント・バージョン] に送信された場合、拒否されるか誤って処理される（`SameSite=Strict` として扱われる）ことがありました。現在、Open Liberty は、`SameSite=None` 属性を持つ Cookie が Web ブラウザーに送信される前にインターセプトし、`User-Agent` が互換性のないクライアント・バージョンを指定しているかどうかをチェックします。互換性のないクライアントが検出された場合、Cookie から `SameSite=None` および `Partitioned` ヘッダー（存在する場合）が削除されます。

詳細については、link:{url-prefix}/blog/2020/03/25/set-samesite-attribute-cookies-liberty.html[Setting the SameSite attribute on cookies with Open Liberty] を参照してください。
