== AES-256 パスワード暗号化のサポート

Open Liberty は、`server.xml` ファイルに保存されるパスワードの Advanced Encryption Standard (AES) 暗号化をサポートしています。この AES 暗号化は、AES-256 ビット・キーを使用するようになりました。AES 復号化では、Open Liberty は AES-128 と AES-256 の両方をサポートしています。以前は、Open Liberty の AES パスワード暗号化と復号化は 128 ビット・キーのみを使用していました。256 ビット・キーはより強力な暗号化を提供し、暗号化されたパスワードをより安全にします。

AES-256 暗号化でパスワードを暗号化するには、`wlp/bin` ディレクトリから `--encoding=aes` オプションを指定して `securityUtility encode` コマンドを実行します。

[source,bash]
----
securityUtility encode --encoding=aes superAES256password
----

レスポンスは、以下の例のような 256 ビット AES 暗号化パスワードです。

[source,bash]
----
{aes}ARAmkTCr3of9G0gvieyx7NtHFbeX5fiueD6yGTvnYzyFMxyg7Cd5V6Ew34uxunYb0pYixwDiR6V2qCx2Yxm9io4KBZiW8T9GJLCut1ClauY7GNBM6lFM+PMZfCaScPzUgSE07PJYI37WQ8lSzjaeWGCA+K5dlA==
----

このパスワードを `server.xml` ファイルで使用できるようになりました。例えば、キーストア定義で使用できます。

[source,xml]
----
<keyStore id="MyKeyStore" password="{aes}ARAmkTCr3of9G0gvieyx7NtHFbeX5fiueD6yGTvnYzyFMxyg7Cd5V6Ew34uxunYb0pYixwDiR6V2qCx2Yxm9io4KBZiW8T9GJLCut1ClauY7GNBM6lFM+PMZfCaScPzUgSE07PJYI37WQ8lSzjaeWGCA+K5dlA==" />
----

詳細については、以下のリソースを参照してください。

- link:{url-prefix}/docs/latest/reference/command/securityUtility-encode.html[securityUtility encode コマンド]
- link:{url-prefix}/docs/latest/password-encryption.html[パスワード暗号化の制限事項]

== 前回のリリース以降の新規および更新されたガイド

Open Liberty の機能が成長し続けるにつれて、それらのトピックに関する link:{url-prefix}/guides/?search=new&key=tag[新しいガイドを openliberty.io に] 追加し、採用を可能な限り簡単にしています。既存のガイドも、報告されたバグや問題に対処し、コンテンツを最新の状態に保ち、トピックのカバー範囲を拡大するために更新されます。

- 新しいガイド link:{url-prefix}/guides/jakarta-faces.html[統合されたユーザー・インターフェースとバックエンド・ロジックを使用した動的 Web アプリケーションの構築] が **Client side** カテゴリーで公開されました。
- **Deprecated** とマークされているガイドを除くすべてのガイドが、MicroProfile 7 と link:{url-prefix}/docs/latest/reference/feature/versionless-features.html[バージョンレス機能] を使用するように更新されました。
- link:{url-prefix}/guides/cloud-azure.html[Azure Kubernetes Service へのマイクロサービスのデプロイ] ガイドが、IBM WebSphere Liberty および Open Liberty on AKS プランを使用してリソース・グループを作成するように更新されました。
