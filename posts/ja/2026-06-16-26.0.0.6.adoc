== 26.0.0.6 を使用したアプリケーションの開発と実行

link:{url-prefix}/guides/maven-intro.html[Maven] を使用している場合は、`pom.xml` ファイルに以下を含めてください:

[source,xml]
----
<plugin>
    <groupId>io.openliberty.tools</groupId>
    <artifactId>liberty-maven-plugin</artifactId>
    <version>3.12.0</version>
</plugin>
----

link:{url-prefix}/guides/gradle-intro.html[Gradle] の場合は、`build.gradle` ファイルに以下を含めてください:

[source,gradle]
----
buildscript {
    repositories {
        mavenCentral()
    }
    dependencies {
        classpath 'io.openliberty.tools:liberty-gradle-plugin:4.0.0'
    }
}
apply plugin: 'liberty'
----

== 前回のリリース以降の新規および更新されたガイド
Open Liberty の機能が成長し続けるにつれて、それらのトピックに関する link:https://openliberty.io/guides/?search=new&key=tag[openliberty.io への新しいガイド]を追加し続けて、採用を可能な限り簡単にしています。既存のガイドも、報告されたバグや問題に対処し、コンテンツを最新の状態に保ち、トピックのカバー範囲を拡大するために更新されます。

* link:https://openliberty.io/guides/microprofile-telemetry-grafana-automatic.html[OpenTelemetry と Grafana を使用したトレース、メトリック、およびログによるマイクロサービスの可観測性の有効化]
+
MicroProfile Telemetry と Grafana スタックを使用して、マイクロサービスからトレース、メトリック、およびログの収集を有効にする方法を学びます。

* link:https://openliberty.io/guides/microprofile-telemetry-grafana-custom.html[OpenTelemetry と Grafana を使用したマイクロサービスの可観測性のためのカスタム・トレースとメトリックの追加] 
+
MicroProfile Telemetry と Grafana スタックを使用して、マイクロサービスからトレース内のカスタム・スパンとカスタム・メトリックを収集するための手動インストルメンテーションを追加する方法を学びます。

* link:https://openliberty.io/guides/jakarta-faces.html[統合されたユーザー・インターフェースとバックエンド・ロジックを使用した動的 Web アプリケーションの構築]

+
Gradle と Open Liberty を使用して複数のモジュールを持つアプリケーションを構築する方法を学びます。
