= Open Liberty 日本語ブログが 2 周年を迎えました
Hiroko Takamiya <https://github.com/una-tapa>

:imagesdir: /
:url-prefix:
:url-about: /
//Blank line here is necessary before starting the body of the post.

2022 年に開設された Open Liberty 日本語ブログは、日本におけるローカライズされた Open Liberty コンテンツへの需要の高まりに応えるために作成されました。
2 周年を迎えるにあたり、私たちの歩みのハイライトと成功を振り返ります。この記事では、読者の皆様に深く共感していただいた最も人気のある投稿を紹介します。

また、この多言語プラットフォームの形成に極めて重要な役割を果たしてくださった、献身的な貢献者と技術専門家の皆様に心から感謝いたします。
彼らの活動は、オープンソース・コミュニティにおけるコラボレーションの精神を体現するだけでなく、私たちのグローバルな知識交換を豊かにしています。

== 人気記事ランキング

最新リリースや新機能の技術的な詳細を紹介する記事が、読者の皆様から注目を集めています。特に、
「link:https://openliberty.io/blog/2023/03/07/23.0.0.2.html[Test database connections and set server stop time out in Open Liberty 23.0.0.2]」や「link:https://openliberty.io/blog/2024/06/18/24.0.0.6.html[Faster startup for Spring Boot 3.x applications and more in 24.0.0.6]」など、特定の設定や新しいサポート機能について詳しく説明する記事が人気です。

さらに、「Open Liberty ガイドを使用してクラウドネイティブな Java アプリケーションを開発し、Kubernetes 環境にデプロイする方法を学ぶ」など、実用的なガイドを提供する記事も多くの関心を集めています。
これらの記事は、最新の技術やツールを効果的に活用したい開発者にとって貴重なリソースとなっています。

ランキングのリンクは英語の記事に移動します。翻訳された記事については、各記事の「Post available in languages:」の見出しをご覧ください。

== 貢献者の紹介

本業の傍ら、自発的に時間を割いてくださった貢献者の皆様から、いくつかのコメントをいただきました。

link:https://www.linkedin.com/in/miyuka-nishio[Miyuka Nishio]

こんにちは、西尾美由香と申します。現在 IBM に入社して 2 年目です。WebSphere Liberty と Open Liberty の技術営業スペシャリストとして、プリセールス活動とコミュニティ管理に携わっています。IBM に入社する前は主に会計の仕事をしていたため、Java 開発の経験はほとんどありませんでした。しかし、上司が私の専門的な成長の一環として Open Liberty ブログの翻訳に参加することを勧めてくれました。この機会により、Liberty の新機能について学び、エンジニアリングスキルを強化することができました。まだ学ぶべきことはたくさんありますが、エンジニアとして成長し続け、Open Liberty プロジェクトに有意義な貢献をしていきたいと思っています。

link:https://www.linkedin.com/in/tsuyoshi-baba-babatch[Tsuyoshi Baba]

私は 1998 年に日本 IBM に入社し、同年の WebSphere Application Server V1.1 の日本でのリリース直後から WebSphere に携わり始めました。当初は製品マーケティングに従事し、その後技術営業に転向し、ビジネスパートナーをサポートしてきました。2022 年に日本 IBM に戻り、現在は技術営業スペシャリストとして WebSphere を含むアプリケーション・モダナイゼーションに注力しています。

トップ記事のランキングは非常に興味深いです。アプリケーションサーバーを起動したら、次のステップは常にデータベースに接続してアプリケーションの構築を開始することのようです。Java EE/Jakarta EE、Java SE、MicroProfile の新バージョンに関する発表も人気があります。そしてもちろん、Spring も引き続き強い存在感を示しています！ARM64 コンテナに関する記事の人気は、新しい Apple Silicon を搭載した Mac を使用する開発者が増えているためかもしれません。私もその一人です。

Open Liberty/WebSphere Liberty の進化を引き続きサポートしていきたいと思います！

link:https://www.linkedin.com/in/atsushi-kurokawa/?originalSubdomain=jp[Atsushi Kurokawa]

私は 2002 年に日本 IBM に入社し、WebSphere Application Server と Rational の技術営業として幅広く活動し、デリバリー部門で提案、コンサルティング、システム開発を提供してきました。2024 年には、軽量アーキテクチャとゼロマイグレーション機能に感銘を受けて Liberty の責任を引き受け、お客様への移行を推奨しています。

私の専門分野は DevOps、特に開発領域です。また、日本の中小企業診断士の資格も持っています。余暇にはサックスを演奏することを楽しんでいます。

link:https://www.linkedin.com/in/kaori-asada-680355142/[Kaori Asada]

技術営業チームのメンバーではないにもかかわらず、Kaori はブログの立ち上げ時に参加し、多数の翻訳を引き受けてくれました。彼女の貢献は、誰でも貢献できるオープンソースの美しさを真に際立たせました。Kaori の助けがなければ、ブログの初期段階を乗り越えることは困難だったでしょう。ありがとう、Kaori！

link:https://www.linkedin.com/in/takakiyo[Takakiyo Tanaka]

同僚や技術コミュニティから「Takakiyo-san」の愛称で親しまれている田中氏は、20 年以上にわたり日本 IBM の技術営業スペシャリストとして、主に WebSphere Application Server と Java テクノロジーに注力してきました。彼は Java とエンタープライズ Java テクノロジーに関する数多くのプレゼンテーションを、さまざまなコミュニティイベントで行ってきました。彼の最初のブログ投稿「link:https://openliberty.io/ja/blog/2022/09/01/openliberty-guides-in-japanese.html[Learn how to develop cloud-native Java applications and deploy them to Kubernetes environments using the Open Liberty Guides. (Japanese only)]」は、常にトップ 10 の人気記事にランクインしています。彼はまた、月次ブログ記事の翻訳も開始し、このブログの成功において極めて重要な役割を果たしています。田中氏の Open Liberty への情熱はコミュニティでよく知られており、link:https://qiita.com/TTakakiyo[日本の技術ウェブサイト]でも見ることができます。

== 成功した 2 年間を振り返って

Open Liberty 日本語ブログの 2 周年を祝うにあたり、コミュニティ主導のアプローチが成功の鍵となったことは明らかです。技術記事の人気は、日本の開発者の特定のニーズと関心に対応するローカライズされたコンテンツへの強い需要を示しています。このコミュニティに引き続きサービスを提供できる機会に感謝し、日本および世界中の Open Liberty ユーザーの成長と発展をサポートする高品質で関連性の高いコンテンツの提供に引き続き注力しながら、これまでに確立した勢いを基に構築していくことを楽しみにしています。
