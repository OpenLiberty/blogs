== JWT BuilderにECDH-ESサポートを追加

Open Libertyは、JSON Web Token 1.0（`jwt-1.0`）機能を強化し、`jwtBuilder`設定に鍵管理アルゴリズムとしてECDH-ES（楕円曲線ディフィー・ヘルマン・エフェメラル・スタティック）のサポートを導入しました。この更新により、アプリケーション開発者は楕円曲線暗号を使用してJSON Web Encryption（JWE）トークンのコンテンツ暗号化キー（CEK）を決定できるようになりました。以前サポートされていたRSA-OAEPに代わる最新の代替手段を提供することで、ECDH-ESを通じてセキュリティが向上します。

ECDH-ESを使用するには、開発者は`keyManagementKeyAlias`属性に楕円曲線（EC）公開鍵を定義する必要があります。EC公開鍵と秘密鍵のペアは、`securityUtility`や`keytool`を使用して生成できます。例えば:

----
./securityUtility createSSLCertificate --sigAlg=SHA256withECDSA --keySize=256 --server=myServer --validity=3650 --password=password
----

----
keytool -genkeypair -alias eccert -keyalg EC -groupname secp256r1 -validity 3650 -storetype pkcs12 -keystore myKeystore.p12 -storepass password
----

ECDH-ESは、JSON Web Token 1.0（`jwt-1.0`）機能の`jwtBuilder`要素の`keyManagementKeyAlgorithm`属性で設定できます。ECDH-ES鍵管理アルゴリズムで使用されるEC公開鍵を`keyManagementKeyAlias`でエイリアスで参照し、`trustStoreRef`属性を使用してキーストアを指定します。

`server.xml`設定例:
[source, xml]
----
<jwtBuilder
    keyManagementKeyAlgorithm="ECDH-ES"
    keyManagementKeyAlias="myECPublicKey"
    trustStoreRef="myTrustStore" ... />
----

`jwtBuilder`の設定の詳細については、link:https://openliberty.io/docs/latest/reference/config/jwtBuilder.html[Open Libertyのドキュメント]を参照してください。
