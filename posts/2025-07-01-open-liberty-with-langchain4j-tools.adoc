= Using Tools to perform tasks in your AI application
Andrew Sasmito <https://github.com/AndrewSasmito>
:imagesdir: /
:url-prefix:

:example-location: https://github.com/OpenLiberty/sample-langchain4j/tree/main/tools


With the recent advances in Artificial Intelligence (AI) come several new cutting-edge features that can transform how people use large language models (LLM). In the past, AI relied on pre-trained knowledge from datasets to generate static responses, struggling with dynamic queries that needed live data. Thus, developers started to train their LLMs so that they gain the ability to call external tools, allowing them to get real-time information and run functions to help automate tasks or enhance their responses. This shifts AI from a passive chatbot to becoming a more proactive helper, allowing the creation of agentic AIs that can perform external tasks for you and more accurate chatbots. See the https://www.ibm.com/think/topics/tool-calling[What is tool calling?] article from IBM to learn more about tool-calling AIs and how they work.

In this post, we explore how to give AI tools in Java applications by using LangChain4j. We also use them in an example Jakarta EE/MicroProfile application.

[#what_Are_LLMs_with_tools]
== What are tools for LLMs?

Some LLM models are able to call tools due to their training data, which improves their response and gives them the ability to perform actions. When an AI is given a prompt that it believes it cannot do, it tries to search for a tool that can best perform the task. This ability greatly enhances LLMs as they can start doing tasks for you or use online APIs and databases to access the web and better their response.

Many models such as Llama, GPT-4.1, and Devstral support the ability to call and run tools. Some can be found on AI providers such as GitHub, Mistral AI, and Ollama.

[#Java_LLMs_Tools]
== How to take advantage of using AI with tools in Java applications?

Creating tools by hand for models can be hard. The open source project LangChain has abstractions and tools to allow for a common interface to use tools for several models.

You can use community projects like https://github.com/langchain4j/langchain4j[LangChain4j] to help speed development with AI and tools. LangChain4j APIs can help integrate LLMs into your Java application for different AI platforms by using one interface. They allow for simple development of integrating tools with several models and providers.

[#how_app_work]
== How does the application work?

The application demonstrates how to use the https://docs.langchain4j.dev/tutorials/tools[LangChain4j Tools], https://openliberty.io/docs/ref/feature/cdi-4.0.html[Jakarta Contexts and Dependency Injection], https://openliberty.io/docs/latest/reference/feature/websocket-2.1.html[Jakarta WebSocket], and https://openliberty.io/docs/ref/feature/mpConfig-3.0.html[MicroProfile Config] features.

Each AI model can only provide static data, which may be outdated based on what it was trained on. You can use the AI tools to enhance the interaction with the AI model by calling other third-party APIs, querying more data from database, or performing complex tasks.

The AI model in this sample application is given tools to search from the https://stackoverflow.com[Stack Overflow website] which developers use to post their questions and answers. This allows users to efficiently search for relevant information from Stack Overflow with the help of AI without leaving the chat application. Those tools give the ability to return additional information from the Stack Overflow beyond the AI model. Thus, if the AI model is prompted with a question that it cannot solve, it uses a matched tool to search on the Stack Overflow. The tool searches questions by using the https://api.stackexchange.com/docs/excerpt-search[StackExchange excerpt-search API] that find the first question similar to what the user is asking. If the question has at least one answer, the tool calls another API to get the top answer and return the question ID, question, and top answer back to the AI model. The AI model parses the data, constructs a reply, and sends the reply to the user.

[#create_tool]
=== Creating the tools

To create functions that the AI can call, it must be annotated with `@Tool` with an explanation so the AI model can understand the purpose of the tool. If any parameters exist, annotating with `@P` helps explain what it represents. Proper annotations help the AI distinguish when to call the tool and what to put as parameters. If the function returns, the AI receives the output and can use it to customize its response back to the user.

The searchStackOverFlow tool uses the https://api.stackexchange.com/[Stack Exchange API] along with JakartaEE methods to call the API and return the response to the AI. There are a few methods to search for questions and answers to different topics on Stack Overflow and a general search method to enhance the AI's response. Here are two of the tools shown below.

See the {example-location}/src/main/java/io/openliberty/sample/langchain4j/StackOverflowTools.java[src/main/java/io/openliberty/sample/langchain4j/StackOverflowTools.java] file to learn more.
[source, java, role="no_copy"]
----
public class StackOverflowTools {
    ...
    private ArrayList<String> questionAndAnswer(String url) throws Exception {
        ArrayList <String> questionAnswer = new ArrayList<>();
        for (Map<String, Object> data : clientSearch(url)) {
            String topAnswer = clientSearch(String.format(findAnswer, data.get("question_id")))
                                    .get(0).get("body").toString();
            questionAnswer.add(
                "Link: " + "https://stackoverflow.com/questions/" + data.get("question_id") + 
                " Problem: " + data.get("body") +
                " Answer: " + topAnswer
            );
        }
        return questionAnswer;
    }
    
    ...

    @Tool("Search for questions and answers on stackoverflow")
    public ArrayList <String> searchStackOverflow(@P("Question you are searching") String question) throws Exception {
        logger.info("AI called the searchStackOverflow Tool with question: " + question);
        String targetUrl = stackOverflowMethod + "&q=" + question;
        return questionAndAnswer(targetUrl);
    }
}
----

[#create_service]
=== Creating the LangChain4j AI service

Start off by injecting a https://github.com/OpenLiberty/sample-langchain4j/blob/3564a2f12e4caea7f2ce627d337d2647eafa5d0e/tools/src/main/java/io/openliberty/sample/langchain4j/ChatAgent.java#L33-L34[StackOverFlowTools] tool instance to the AI service. Then configure the service with the model and the tool instance by the https://github.com/OpenLiberty/sample-langchain4j/blob/3564a2f12e4caea7f2ce627d337d2647eafa5d0e/tools/src/main/java/io/openliberty/sample/langchain4j/ChatAgent.java#L58[tools] parameter so that the service can use the tools.

The AI service is also configured with a https://github.com/OpenLiberty/sample-langchain4j/blob/3564a2f12e4caea7f2ce627d337d2647eafa5d0e/tools/src/main/java/io/openliberty/sample/langchain4j/ChatAgent.java#L59[hallucinatedToolNameStrategy] in case that it tries to call a tool that does not exist. The hallucinatedToolNameStrategy lets the developer create a message, which indicates to the model that it used a nonexistent tool. Afterward, the AI can try to call another tool.

See the {example-location}/src/main/java/io/openliberty/sample/langchain4j/ChatAgent.java[src/main/java/io/openliberty/sample/langchain4j/ChatAgent.java] file.
[source, java, role="no_copy"]
----
    public Assistant getAssistant() {
        ...
            ChatModel model = modelBuilder.getChatModel();
            assistant = AiServices.builder(Assistant.class)
                .chatModel(model)
                .tools(stackOverflowTools)
                .hallucinatedToolNameStrategy(toolExecutionRequest -> ToolExecutionResultMessage.from(
                    toolExecutionRequest, "Error: there is no tool with the following parameters called " + toolExecutionRequest.name()))
                .chatMemoryProvider(
                    sessionId -> MessageWindowChatMemory.withMaxMessages(MAX_MESSAGES))
                .build();
       ...
    }
----

Through the customized `Assistant` interface, the application can send messages to the LLM by the `chat()` method along with the system message that tells the AI what its role and tasks are.

See the {example-location}/src/main/java/io/openliberty/sample/langchain4j/ChatAgent.java[src/main/java/io/openliberty/sample/langchain4j/ChatAgent.java] file.
[source, java, role="no_copy"]
----
    interface Assistant {
        @SystemMessage("You are a coding helper, people will go to you for questions around coding. " +
            "You have ONLY four tools. " +
            "ONLY use the tools if NECESSARY. " +
            "ALWAYS follow the tool call parameters exactly and make sure to provide ALL necessary parameters. " +
            "Do NOT add more parameters than needed" + 
            "NEVER give the user unnecessary information. " + 
            "NEVER lie or make information up, if you are unsure say so.")
        String chat(@MemoryId String sessionId, @UserMessage String userMessage);
    }
----

[#communicate]
=== Communicating between the client and LLM

The application provides the interactive UI for users to communicate with the LLM. Jakarta WebSocket enables two-way communication between the client and the `ChatService` service. Each client makes an HTTP connection to the service and sends messages using the `send()` method.

See the {example-location}/src/main/webapp/toolChat.js[src/main/webapp/toolChat.js] file.
[source, java, role="no_copy"]
----

    const webSocket = new WebSocket(uri);
    ...
    function sendMessage() {
        ...
        var myMessage = document.getElementById('myMessage').value;
        ...
        webSocket.send(myMessage);
        ...
    }
----

The service receives the user messages through the WebSocket `onMessage()` method, forwards them to the LLM by calling the `ChatAgent.chat()` method, and then responds with the LLM answers back to the client through the `sendObject()` method.

See the {example-location}/src/main/java/io/openliberty/sample/langchain4j/ChatService.java[src/main/java/io/openliberty/sample/langchain4j/ChatService.java] file.
[source, java, role="no_copy"]
----

    @OnMessage
    public void onMessage(String message, Session session) {
        ...
        try {
            ...
            answer = agent.chat(sessionId, message);
        } catch (Exception e) {
            ...
        }

        try {
            session.getBasicRemote().sendObject(answer);
        } catch (Exception e) {
            e.printStackTrace();
        }

    }
----
