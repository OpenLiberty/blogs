== 使用 26.0.0.8 开发和运行应用程序

如使用 link:{url-prefix}/guides/maven-intro.html[Maven]，在您的 `pom.xml` 文件中添加以下插件配置：

[source,xml]
----
<plugin>
    <groupId>io.openliberty.tools</groupId>
    <artifactId>liberty-maven-plugin</artifactId>
    <version>3.12.1</version>
</plugin>
----

如使用 link:{url-prefix}/guides/gradle-intro.html[Gradle]，在您的 `build.gradle` 文件中添加：

[source,gradle]
----
buildscript {
    repositories {
        mavenCentral()
    }
    dependencies {
        classpath 'io.openliberty.tools:liberty-gradle-plugin:4.0.0'
    }
}
apply plugin: 'liberty'
----
