== 对 Java 27 的支持

Java 27 是 Java 的最新版本。它包含了一些相比以往 Java 版本的新特性和增强功能，值得关注。这并不是一个长期支持（LTS）版本。

Java 27 中包含 9 个新特性（JEP）。其中 5 个是测试特性，4 个已完全交付：

*测试特性：*

* 531: link:https://openjdk.org/jeps/531[惰性常量（第三次预览）]
* 532: link:https://openjdk.org/jeps/532[模式、instanceof 和 switch 中的基本类型（第五次预览）]
* 533: link:https://openjdk.org/jeps/533[结构化并发（第七次预览）]
* 537: link:https://openjdk.org/jeps/537[Vector API（第十二次孵化）]
* 538: link:https://openjdk.org/jeps/538[加密对象的 PEM 编码（第三次预览）]

*交付特性：*

* 523: link:https://openjdk.org/jeps/523[在所有环境中将 G1 设置为默认垃圾收集器]
* 527: link:https://openjdk.org/jeps/527[TLS 1.3 的后量子混合密钥交换]
* 534: link:https://openjdk.org/jeps/534[默认紧凑对象头]
* 536: link:https://openjdk.org/jeps/536[JFR 进程内数据脱敏]

关于 JEP 523 的重要说明 —— JEP 523 更改了 Java 27 中的默认垃圾收集器。G1 垃圾收集器（GC）现在在所有环境中都是默认设置，包括之前使用 Serial 或 Parallel GC 的环境，例如单 CPU 或低内存环境（如容器）。如果您在受限环境中运行 Liberty，可能会注意到与早期 Java 版本不同的 GC 行为。要恢复为之前的垃圾收集器，请使用 `-XX:+UseSerialGC` 或 `-XX:+UseParallelGC`。

立即体验这些新变更，并有更多时间预览在 Java 27 上运行的应用程序和微服务。

下载 link:https://developer.ibm.com/languages/java/semeru-runtimes/downloads/[IBM Semeru Runtimes 27] 或 link:https://jdk.java.net/27/[Java 27]，下载并安装 link:https://openliberty.io/downloads/#runtime_releases[26.0.0.10]，在 Liberty 服务器的 link:https://openliberty.io/docs/latest/reference/config/server-configuration-overview.html#server-env[`server.env`] 文件中将 `JAVA_HOME` 设置为您的 Java 27 安装目录，即可开始测试。

有关 Java 27 的更多信息，请参阅 Java 27 link:https://jdk.java.net/27/release-notes[发布说明页面]、link:https://download.java.net/java/early_access/jdk27/docs/api/[Javadoc] 或 link:https://jdk.java.net/27/[下载页面]。
有关 Open Liberty 的更多信息，请参阅我们的 link:https://openliberty.io/docs[文档页面]。

== 使用 26.0.0.10 开发和运行应用程序

如果您使用 link:{url-prefix}/guides/maven-intro.html[Maven]，请在 `pom.xml` 文件中包含以下内容：

[source,xml]
----
<plugin>
    <groupId>io.openliberty.tools</groupId>
    <artifactId>liberty-maven-plugin</artifactId>
    <version>3.12.3</version>
</plugin>
----

或者，如果您使用 link:{url-prefix}/guides/gradle-intro.html[Gradle]，请在 `build.gradle` 文件中包含以下内容：

[source,gradle]
----
buildscript {
    repositories {
        mavenCentral()
    }
    dependencies {
        classpath 'io.openliberty.tools:liberty-gradle-plugin:4.0.2'
    }
}
apply plugin: 'liberty'
----
