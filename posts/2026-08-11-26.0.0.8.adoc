== Develop and run your apps using 26.0.0.8

If you're using link:{url-prefix}/guides/maven-intro.html[Maven], include the following in your `pom.xml` file:

[source,xml]
----
<plugin>
    <groupId>io.openliberty.tools</groupId>
    <artifactId>liberty-maven-plugin</artifactId>
    <version>3.12.1</version>
</plugin>
----

Or for link:{url-prefix}/guides/gradle-intro.html[Gradle], include the following in your `build.gradle` file:

[source,gradle]
----
buildscript {
    repositories {
        mavenCentral()
    }
    dependencies {
        classpath 'io.openliberty.tools:liberty-gradle-plugin:4.0.0'
    }
}
apply plugin: 'liberty'
----

== Notable bugs fixed in this release


We’ve spent some time fixing bugs. The following sections describe the issues resolved in this release. If you’re interested, here’s the  link:https://github.com/OpenLiberty/open-liberty/issues?q=label%3Arelease%3A26008+label%3A%22release+bug%22[full list of bugs fixed in 26.0.0.8].

* link:https://github.com/OpenLiberty/open-liberty/issues/35316[IBM WebSphere Application Server Liberty is affected by a security bypass vulnerability (CVE-2026-10842)]
* link:https://github.com/OpenLiberty/open-liberty/issues/35243[PasswordUtil.encode() misinterprets {algo} plaintext passwords as pre-encoded ciphertext]
* link:https://github.com/OpenLiberty/open-liberty/issues/35187[LTPAToken2 does not support Pipe symbol properly when verifying incoming tokens]
* link:https://github.com/OpenLiberty/open-liberty/issues/35130[NoSuchMethodException from two 3.X versions of jboss.logging]

* link:https://github.com/OpenLiberty/open-liberty/issues/35076[Update Expression Language 5.0 API and IMPL version 10.1.55]
* link:https://github.com/OpenLiberty/open-liberty/issues/35037[IllegalStateExceptions about no UnitOfWork on the thread]
